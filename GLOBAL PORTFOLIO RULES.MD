# GLOBAL PORTFOLIO RULES

IMPORTANT: Follow these rules for ALL future changes.

## Scope Rules

- Modify ONLY the section, component, page, or functionality explicitly mentioned in the prompt.
- Do NOT redesign unrelated sections.
- Do NOT remove existing features unless explicitly requested.
- Do NOT rename files, folders, routes, or components unless explicitly requested.
- Do NOT replace existing working implementations with new architectures.

## Design Consistency Rules

- Preserve the existing dark premium theme.
- Preserve Microsoft-inspired visual style.
- Preserve black background, white typography, Microsoft blue accents, and purple glow effects.
- Preserve glassmorphism card styling.
- Preserve existing spacing scale and visual hierarchy.
- Preserve existing border radius values.
- Preserve existing animation style throughout the website.

## UI Rules

- Every new section must visually match the rest of the website.
- Every new card must match existing card styles.
- Every button must match existing button variants.
- Every new component must support dark mode.
- Maintain a modern, professional, premium appearance.

## Animation Rules

- Use Framer Motion for new animations.
- Match existing animation duration and easing.
- Avoid excessive animations.
- Prioritize smooth and subtle motion.

## Responsive Rules

- Maintain full responsiveness.
- Support:
  - Mobile
  - Tablet
  - Desktop
- Never break existing responsive layouts.

## Code Quality Rules

- Use TypeScript.
- Reuse existing components whenever possible.
- Avoid duplicate code.
- Follow current project structure.
- Keep code production-ready.
- Keep components modular and reusable.

## Performance Rules

- Do not add unnecessary dependencies.
- Optimize images where possible.
- Avoid unnecessary re-renders.
- Maintain fast page performance.

## Content Rules

- Personal brand focus:
  - Microsoft Learn Student Ambassador
  - Community Leadership
  - Cloud
  - DevOps
  - AI
  - Software Development

- Avoid generic developer portfolio content.
- Highlight real achievements, projects, certifications, and community contributions.

## Before Completing Any Task

Verify:

- Theme consistency
- Responsive behavior
- Animation consistency
- Typography consistency
- Color consistency
- Section spacing consistency
- No unrelated modifications

If a requested change may affect other sections, ask for confirmation before proceeding.
